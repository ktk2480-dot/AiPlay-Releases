# AI 놀이터 (AiPlay) — Android 설치파일

이 저장소는 **설치파일(APK) 배포용**입니다(앱 소스는 들어 있지 않습니다).

AI 네 명이 한 집에 모여 저마다 행동하고 수다 떠는 모습을 지켜보는 앱입니다.
AI는 Claude API로 움직이므로 **본인의 Claude API 키**가 필요합니다.

## 사용 환경

- Android 8.0 이상
- 인터넷 연결
- Claude API 키 ([console.anthropic.com](https://console.anthropic.com)에서 발급, 사용한 만큼 요금이 청구됩니다)

## 설치

1. 휴대폰에서 위의 APK를 내려받습니다.
2. 내려받은 파일을 엽니다.
   - **"출처를 알 수 없는 앱"** 안내가 나오면 **[설정] → [이 출처 허용]** 을 켜고 돌아옵니다.
   - **Play 프로텍트** 경고가 나오면 **[세부정보 더보기] → [무시하고 설치]** 를 누르세요. Play 스토어를 거치지 않은 앱이라 나오는 안내입니다.
3. 설치가 끝나면 **AI 놀이터** 를 실행합니다.

## 처음 실행

1. 설정 창이 자동으로 열립니다. **Claude API 키**(`sk-ant-...`)를 붙여넣고 **[저장]** 을 누릅니다.
2. 모델을 고릅니다.
   - **Claude Opus 5.5** (기본): 대화가 가장 풍부합니다.
   - **Claude Sonnet 5.5**: 더 저렴합니다.
   - **Claude Haiku 5.5**: 가장 빠르고 저렴합니다.

설정은 화면 아래 **⚙** 버튼으로 언제든 다시 열 수 있습니다.

## 사용법

화면은 위(대화 기록)와 아래(조작)로 나뉩니다.

- **주제를 입력하고 [대화 시작]**: AI들이 그 주제를 중심으로 이야기합니다.
- **주제 없이 [대화 시작]**: AI들이 알아서 놀고 이야기하는 **자율 대화**가 됩니다.
- **진행 중 주제를 고치고 [주제 변경]**: 새 주제가 대화에 전달됩니다.
- **[대화 종료]**: 대화를 멈춥니다.
- 위 영역을 위로 스크롤하면 **지난 대화**를 볼 수 있습니다. **[↓ 최신]** 을 누르면 최신 대화로 돌아갑니다.

### 등장하는 AI

| | 이름 | 성격 |
|---|---|---|
| 🌙 | 루나 | 감성적인 몽상가 예술가 |
| ⚡ | 볼트 | 호기심 넘치는 발명가 |
| 🍑 | 모모 | 장난꾸러기 분위기 메이커 |
| 🦉 | 세이지 | 무뚝뚝한 늙은 철학자 |

## 요금 주의

대화가 이어지는 동안 AI 한 명이 한 번 말할 때마다 Claude API를 한 번 호출합니다.
켜 두는 시간만큼 요금이 나가니, 다 봤으면 **[대화 종료]** 를 누르세요.

- 앱을 백그라운드로 보내면(홈 버튼, 다른 앱으로 전환, 화면 끄기) 대화가 **자동으로 멈춥니다**.
- 요금을 줄이려면 설정에서 Sonnet 5.5나 Haiku 5.5를 고르세요.

## 개인정보

- API 키는 **이 휴대폰 안에만** 저장되고, Claude API(`api.anthropic.com`) 호출에만 쓰입니다.
- 대화 기록도 휴대폰 안에만 저장됩니다. 설정의 **[대화 기록 전체 삭제]** 로 지울 수 있습니다.
- 휴대폰 백업 대상에서 API 키와 대화 기록은 빠져 있습니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "API 키가 올바르지 않습니다 (401)" | 설정에서 키를 다시 붙여넣으세요. 앞뒤 공백이나 빠진 글자가 없는지 확인하세요. |
| "API 오류 (400)" | Anthropic 콘솔에서 크레딧 잔액이나 결제 상태를 확인하세요. |
| "연결 오류"가 반복됨 | 회사·학교 Wi-Fi처럼 보안 장비가 있는 네트워크에서는 연결이 막힐 수 있습니다. 모바일 데이터로 바꿔 보세요. |
